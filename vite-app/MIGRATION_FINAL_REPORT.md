## 开发工具和脚本

### 🛠️ 切换脚本
- **switch-version.bat** (Windows)
- **switch-version.sh** (Linux/macOS)

```bash
# 启动TypeScript版本
./switch-version.sh modern

# 启动原版本对比
./switch-version.sh original

# 查看运行状态
./switch-version.sh status
```

## 部署指南

### 开发环境
```bash
cd vite-app
npm install
npm run dev
# http://localhost:3000
```

### 生产部署
```bash
cd vite-app  
npm run build
npm run preview
# http://localhost:3001
```

### 服务器要求
- **静态文件服务器**: Apache, Nginx, 或任何HTTP服务器
- **浏览器支持**: Chrome 61+, Firefox 60+, Safari 10.1+
- **HTTPS支持**: 推荐用于PWA特性
